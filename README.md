#### 操作教程

1.  将根目录下sql导入本地数据库还原
2.  对数据库商品表goods进行本地维护（增删改查）
3.  找到script文件夹下test.py脚本修改src_directory和dest_directory
4.  运行test.py脚本，生成的json数据将复制替换到指定的静态项目中
5.  将静态项目提交到github或某云储存服务中，完成静态站点的内容更新
